# 🍅 Pomodoro Program

Um simples e eficiente temporizador Pomodoro escrito em Python para ajudar a aumentar sua produtividade e manter o foco nas tarefas diárias.

## 📖 Sobre o Projeto

Este projeto implementa a **Técnica Pomodoro**, um método de gerenciamento de tempo focado em intercalar períodos de trabalho intenso (tradicionalmente de 25 minutos) com curtos intervalos de descanso. É a ferramenta ideal para estudantes, desenvolvedores e qualquer pessoa que queira evitar a fadiga mental e melhorar a concentração.

## ✨ Funcionalidades

*(Ajuste esta lista conforme as funções reais do seu script)*
* ⏱️ Temporizador automático para ciclos de foco (25 min) e pausas curtas (5 min).
* ☕ Pausa longa automática após 4 ciclos completos de foco.
* 🖥️ Execução leve e direta via terminal/linha de comando.
* 🔔 Alertas indicando o início e fim de cada sessão.
